# 01: Restore cake size and flavor when editing a custom-order line item

**What to build:** After Edit, the size step shows the same cake size, flavor, and shape already saved on that line item. A set or combo shows its box count and flavors again. The cart estimate stays the one the customer already saw. If the catalog no longer has that choice, the picker stays empty and the saved names stay on the line item. Edit still opens on the category step.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Editing a standard cake selects the saved diameter, flavor, and shape again
- [ ] A multi-tier cake selects each saved tier flavor
- [ ] A set or combo selects its saved box count and flavors
- [ ] A missing catalog choice does not blank the saved names or the estimate
